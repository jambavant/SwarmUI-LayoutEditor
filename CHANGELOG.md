# Changelog

## 0.2.0

- Opens from the **+** menu beside the prompt (Layout Editor (boxes)), instead of a separate button.
- Multi-selection: Ctrl/Cmd+click, Ctrl-drag rectangle, Ctrl+A; move, nudge, retype, duplicate and delete together.
- Group tools: align, space evenly, center on canvas, same width/height, lock/hide all.
- **+ Add** button and **N** key: add a box in a free spot, even when the canvas is full.
- A selected box no longer jumps above overlapping boxes.
- Code style aligned with SwarmUI's JS and C# guidelines.

## 0.1.0

- First version: MOSS-Image layout editor in a SwarmUI modal, with Apply, Generate (results under the boxes), keep seed, underlay, snapping, layers, checks, live JSON, autosave and named layouts.
- Standalone page.
